Method & data

  

  
Shelly follows CRISP-DM: business targets → data-quality checks → preparation → five competing forecast models, anomaly detection, K-means segmentation, JIT reorder and labour planning → rolling-origin evaluation (cross-checked in R) → this page, an Excel workbook, SQL, Power BI and Tableau outputs.

  
All data here is synthetic, generated to behave like a small Auckland convenience store. No employer data is used.
