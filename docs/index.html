    Product segments

    What is this?

    Products grouped by how they behave (speed, margin, volatility, waste, delivery share, promo response) using K-means, shown on 2 PCA axes. Stability scores show which groups are real and which are noise.

    How good are the forecasts?

    What is this?

    Five models compete on each category: Naive, Seasonal Naive, Drift, SARIMA-X and XGBoost. Each is scored on the last 4 weeks (rolling origin) and the winner is used. A simple model is allowed to win.

    In-depth guide →
    Error by model (WAPE, lower is better)

    Method & data

    What is this?

    How Shelly works end to end (CRISP-DM) and how it checks the data first: duplicates, refunds keyed as sales, missing values, calendar gaps and unknown SKUs, summarised in a quality score.

    In-depth guide →

    Shelly follows CRISP-DM: business targets → data-quality checks → preparation → five competing forecast models, anomaly detection, K-means segmentation, JIT reorder and labour planning → rolling-origin evaluation (cross-checked in R) → this page, an Excel workbook, SQL, Power BI and Tableau outputs.

    All data here is synthetic, generated to behave like a small Auckland convenience store. No employer data is used.
